# REQ-002 - 富文本提交与展示系统

## 1. 需求概述

### 1.1 功能描述
提供一个网页界面，允许用户提交富文本内容，并以列表形式展示所有提交的内容。系统需要支持搜索、分页加载、一键复制等功能，所有数据持久化存储在服务器端。

### 1.2 用户场景
- 匿名用户访问页面，输入文本后提交
- 用户查看历史提交内容列表
- 用户通过时间或关键字搜索特定内容
- 用户一键复制某条提交内容

## 2. 功能需求

### 2.1 文本提交功能

#### 2.1.1 输入要求
- **富文本输入框**：支持多行文本输入
- **内容保留**：
  - 保持原始格式，不删除、不合并空格
  - 保留所有不可见字符（回车 `\n`、换行 `\r\n`、Tab `\t` 等）
  - 不 trimming 首尾空白
- **大小限制**：单条数据不超过 1MB
- **必填项**：输入框不能为空

#### 2.1.2 提交行为
- 点击提交按钮后，将输入内容发送到服务器
- 提交成功后，清空输入框
- 显示提交成功提示
- 新提交的内容自动出现在列表顶部

### 2.2 内容展示功能

#### 2.2.1 列表展示
- **排序方式**：按时间降序排列（最新的在最前面）
- **显示内容**：
  - 提交时间（格式化显示）
  - 内容预览（支持展开/收起）
  - 复制按钮
- **分页加载**：支持下拉加载更多（无限滚动）

#### 2.2.2 一键复制
- 每条数据配备"复制"按钮
- 点击按钮将完整内容复制到剪贴板
- 复制成功显示提示（如"已复制"）
- 复制内容必须与原始数据完全一致（包括所有空白字符和不可见字符）

### 2.3 搜索功能

#### 2.3.1 时间搜索
- 支持按日期范围筛选
- 提供日期选择器（开始日期、结束日期）
- 支持快捷选项（今天、本周、本月、全部）

#### 2.3.2 关键字搜索
- 支持全文搜索
- 搜索范围：提交内容全文
- 高亮显示匹配的关键字
- 支持大小写敏感/不敏感选项

#### 2.3.3 组合搜索
- 支持时间和关键字组合搜索
- 搜索条件可重置

### 2.4 分页与加载

#### 2.4.1 下拉刷新
- 页面滚动到底部时自动加载下一页
- 显示加载状态提示
- 无更多数据时显示提示
- 支持手动刷新（下拉动作）

#### 2.4.2 分页参数
- 每页显示数量：可配置（建议 20-50 条）
- 支持跳转到指定页

## 3. 非功能需求

### 3.1 性能要求
- 页面加载时间：< 2 秒
- 提交响应时间：< 1 秒
- 搜索响应时间：< 2 秒
- 支持并发用户数：至少 100 人

### 3.2 数据要求
- **存储位置**：`data/` 目录下的单个文件
- **文件格式**：JSON Lines (`.jsonl`) 或 JSON 数组
- **文件大小限制**：单条数据 ≤ 1MB
- **字符编码**：UTF-8
- **数据完整性**：确保写入原子性，避免数据损坏

### 3.3 用户体验
- **界面风格**：美观、大方
- **响应式设计**：支持桌面端和移动端
- **交互反馈**：
  - 提交成功/失败提示
  - 复制成功提示
  - 加载状态指示
- **无障碍访问**：支持键盘操作

### 3.4 技术约束
- **前端框架**：Bootstrap v4.6.3（已存在于 `app/static/` 目录）
- **后端框架**：Flask
- **数据存储**：本地文件存储
- **浏览器兼容**：Chrome、Firefox、Safari、Edge 最新版本

### 4.2 数据模型

#### 4.2.1 提交记录结构
```json
{
  "id": "uuid-string",
  "content": "用户提交的原始文本内容",
  "created_at": "2026-03-16T10:30:00+08:00",
  "ip_address": "127.0.0.1",
  "user_agent": "Mozilla/5.0..."
}
```

#### 4.2.2 存储文件格式
采用 JSON Lines 格式（每行一个 JSON 对象）：
```json
{"id": "uuid1", "content": "第一条内容", "created_at": "2026-03-16T10:30:00+08:00"}
{"id": "uuid2", "content": "第二条内容", "created_at": "2026-03-16T10:29:00+08:00"}
```

### 4.3 API 设计

#### 4.3.1 提交接口
- **URL**: `POST /api/v1/submissions`
- **请求体**:
  ```json
  {
    "content": "用户提交的文本内容"
  }
  ```
- **响应**:
  ```json
  {
    "success": true,
    "data": {
      "id": "uuid-string",
      "created_at": "2026-03-16T10:30:00+08:00"
    },
    "message": "提交成功"
  }
  ```

#### 4.3.2 获取列表接口
- **URL**: `GET /api/v1/submissions`
- **查询参数**:
  - `page`: 页码（默认 1）
  - `per_page`: 每页数量（默认 20，最大 100）
  - `start_date`: 开始日期（可选）
  - `end_date`: 结束日期（可选）
  - `keyword`: 搜索关键字（可选）
  - `case_sensitive`: 是否区分大小写（默认 false）
- **响应**:
  ```json
  {
    "success": true,
    "data": {
      "items": [...],
      "total": 100,
      "page": 1,
      "per_page": 20,
      "total_pages": 5
    }
  }
  ```

#### 4.3.3 获取单条接口
- **URL**: `GET /api/v1/submissions/<id>`
- **响应**:
  ```json
  {
    "success": true,
    "data": {
      "id": "uuid-string",
      "content": "完整内容",
      "created_at": "2026-03-16T10:30:00+08:00"
    }
  }
  ```

#### 4.4.2 组件说明

   - 实时显示字符计数

2. **提交按钮**
   - 禁用状态：输入为空时禁用
   - 加载状态：提交时显示 loading 动画
   - 成功反馈：提交成功后显示提示

3. **搜索栏**
   - 日期选择器：使用 Bootstrap Datepicker
   - 关键字输入框：支持实时搜索
   - 搜索按钮：触发自定义搜索
   - 重置按钮：清除所有搜索条件

4. **列表项**
   - 时间显示：格式化显示（YYYY-MM-DD HH:mm:ss）
   - 内容区域：支持展开/收起
   - 复制按钮：点击复制完整内容

## 5. 安全考虑

### 5.1 输入验证
- 内容长度限制：≤ 1MB
- 禁止执行：不执行任何 HTML/JavaScript 渲染
- 字符编码：统一 UTF-8

### 5.2 文件安全
- 文件写入：使用原子操作（先写临时文件，再重命名）
- 并发控制：使用文件锁避免并发写入冲突
- 权限控制：仅允许应用用户读写

### 5.3 防滥用
- 频率限制：同一 IP 每分钟最多提交 10 次
- 内容审核：可选（后续扩展）
